A = (10, 16), B = (10, 36), C = (10, 25). On the right, A is inside, B is outside, and C is on the diagonal boundary and included.

Inverse-mapping only the triangle’s vertices would incorrectly include B on the right. The corrected selector projects each point through the captured log/sqrt scales before testing membership.

This uses the internal CPU selector and a separate highlight layer, as in the million-cell prototype. These are synthetic geometry test points; no download is needed.

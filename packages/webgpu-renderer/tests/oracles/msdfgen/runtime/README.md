# Canonical msdfgen test oracle

This development-only runtime is generated from the dependency-free core of
[`msdfgen` v1.13](https://github.com/Chlumsky/msdfgen/tree/v1.13) at commit
`1874bcf7d9624ccc85b4bc9a85d78116f690f35b`.

`wasmBinary.js` is generated by `tools/msdfgen/build.mjs` using Emscripten
6.0.9. The GenomeSpy-owned loader exposes only the versioned path-rasterization
ABI. The original source, exact source mapping, local wrapper, and reproducible
build command are retained in the repository under `tools/msdfgen/`. The
sources, generated runtime, loader, and comparison adapters are excluded from
the published package and ordinary browser bundles.

The upstream MIT license is preserved in `LICENSE.txt`.

# GenomeSpy UI Components

These reusable Lit web components are used across GenomeSpy apps, including
GenomeSpy App and Playground. They are free to use under the MIT license. The
APIs may change in any release.

## Install and register

```sh
npm install @genome-spy/ui-components lit
```

Import each element's `define/` entry to register it. Import its class from the
package root or the component subpath when you need to subclass or register it
yourself. Open a component's **Docs** page for its properties, attributes,
events, slots, CSS custom properties, and shadow parts.

```js
import "@genome-spy/ui-components/define/splitPanel";
```

Playground gives the split panel a bounded layout and labels its named children
so users can identify the resize handle.

```html
<gs-split-panel style="height: 24rem">
    <div slot="plot" data-pane-label="Visualization"></div>
    <section slot="workspace" data-pane-label="Workspace"></section>
</gs-split-panel>
```

## Connect data and actions

Use Lit property bindings for arrays, callbacks, and objects. App uses
`gs-upload-drop-zone` to pick or drop files, validates the `FileList` from
`event.detail.files`, then gives parsed rows to a bounded `gs-data-grid` for
preview.

```js
import { html } from "lit";
import "@genome-spy/ui-components/define/dropZone";
import "@genome-spy/ui-components/define/dataGrid";

const importPreview = (rows, readFiles) => html`
    <gs-upload-drop-zone
        accept=".csv,.tsv"
        @gs-files-chosen=${(event) => readFiles(event.detail.files)}
    ></gs-upload-drop-zone>
    <gs-data-grid .items=${rows} style="height: 240px"></gs-data-grid>
`;
```

The focused apps use caller-owned job state in their app shell. With
`gs-job-progress`, pass a fresh `.activity` object when the job state changes,
set `.progress` to a fraction or `null`, and handle `gs-job-cancel` through the
job runner. See **Components → JobProgress** for the running, cancelling, and
completed states.

See **Utilities → Form Helpers** for field binding, validation, and multi-step
dialogs.

## Apply a theme

Set `--gs-*` CSS custom properties on a common ancestor. The **Theme** toolbar
and **Theming → Scoped palettes** show the Playground and focused-app palettes,
plus the App button treatment. For dialogs opened by a helper, pass that same
ancestor as `mount` to inherit its theme.

The npm package exposes the generated Custom Elements Manifest at
`@genome-spy/ui-components/custom-elements.json` for editors and other tools.

How this example uses the API

assessQuery() and assessAnnotations() check whether this scope and point geometry support the action.

Two queryData() calls use the same scope and disclosed fields. The first filters by thresholds and aggregates qualifying genes by pathway. The second uses a grouped window with row_number and count, then keeps rank one. Equal scores are resolved by gene name. Window sorting controls rank, not returned row order.

Only the row-preserving query requests annotation targets. annotations.replace() applies labels, connectors, and purple outlines while keeping pathway colors. inspect() reports their count and invalidation, clear() removes labels, and dispose() releases resources on page exit.

Scroll to zoom, drag to pan, and Shift-drag to brush. Queries inspect loaded data in data space. Labels follow navigation; changing the data clears them. Switching to contrast B lowers IFN01's prepared score so IFN02 becomes its pathway's representative.

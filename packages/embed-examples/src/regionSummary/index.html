How this example uses the API

getScaleResolution("x") accesses an unnamed scale for navigation. assessQuery() checks the requested scope. queryData() reads every matching loaded observation with limit: null. The example computes count, mean, minimum, and maximum in ordinary JavaScript, then shows five rows.

GenomeSpy resolves viewport and brush membership. The application chooses and computes the statistics from the returned records. A cleared brush in brush mode matches no rows. Superseded queries are canceled.

The 300–500 range has 20 observations with mean signal 0.6. Source coverage in a transformed query remains unknown, even though this toy eager source is completely loaded.

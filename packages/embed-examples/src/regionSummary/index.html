Why these API additions are needed

GenomeSpy loads the JSON file and derives a percent field. view.readData({limit: 10000}) returns those transformed records. The page rejects a truncated read before computing statistics.

Existing getScaleResolutionByName("position") and getSelection("region").getValue() supply the viewport and brush. Page code filters these known point coordinates, computes the statistics, and chooses a five-row preview. A cleared brush matches no rows in brush mode.

The old scale and brush APIs supplied bounds, but could not enumerate the records inside them. Readback fills that gap without a combined query or analysis API. The high range contains 20 observations with mean 0.6.

How this example uses the API

getScaleResolution("x") accesses an unnamed scale for navigation. assessQuery() checks the requested scope, and queryData() calculates aggregates over every matching loaded observation before limiting the row preview to five.

The application formats the returned results. GenomeSpy performs the viewport/brush filtering and aggregation in the browser. A cleared brush in brush mode matches no rows. Superseded queries are canceled.

The 300–500 kb gain region has 20 observations with mean signal 0.6. Source coverage in a transformed query remains unknown, even though this toy eager source is completely loaded.

Why these API additions are needed

GenomeSpy loads the JSON file. The page reads its records with view.readData({limit: 10000}), uses existing named scales and brush values to filter the range, then applies both thresholds in JavaScript. It sends every qualifying key to getSelection("chosen").setValue(keys).

The spec declares encoding.key and conditional size/opacity. Clicking records and setting keys update the same native selection and subscribed table. Zero thresholds select all 12 records in the whole viewport. There is no ranking or sampling.

The old API could read or clear a point selection, but could not set its membership. Ordinary variable parameters could already drive custom highlighting; this setter is needed when an app wants native selection state, events, and conditional encodings. “Point” means individual records, including records drawn as text or rectangles.

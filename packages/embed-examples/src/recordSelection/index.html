How this example uses the API

queryData() reads the loaded viewport records, optionally intersected with the brush. This example applies both thresholds in ordinary JavaScript, then calls getSelection("chosen").setValue(keys) with every qualifying record's key. It does not rank or sample the matches.

The spec declares encoding.key and conditional size and opacity encodings. The same selection can be changed by clicking records or by the API. Point selections refer to records and also work with text, rectangles, and other marks.

Scroll to zoom, drag to pan, and Shift-drag to brush. Apply thresholds again after changing the scope. The host clears membership before replacing the dataset; it can then select records from the new publication. A cleared brush in brush mode matches no rows. Download SVG preserves the same styling.

Optional visualization controls

Hover over the plot or focus it with the keyboard to reveal its floating controls. Download PNG or SVG, or expand the plot to fill this window. Press Escape or the restore button to return to the page. Zooming and selections are preserved when expanding and restoring.

Shift-drag across the points to select a region. Scroll over the plot to zoom. The bug button opens the Inspector. Image downloads include the current visualization state.

Changing controls preserves the current plot state. This page provides margins above and below the plot for outside controls.

The red Record button captures a silent WebM video of the plot, up to 60 seconds of active recording. Pause lets you adjust the view without recording; Resume continues the clip. Stop downloads it, even while paused. Tooltips and controls are excluded; transparent areas become white. Resizing or hiding this tab cancels recording. The recording PoC targets desktop Chrome with all three renderers.

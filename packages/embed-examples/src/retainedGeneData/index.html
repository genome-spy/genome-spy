How this example uses the API

data.retainForInspection: true retains loaded rows before view transforms. readSourceData(track, {limit: null}) returns all eight retained genes. readData(track, {limit: 1000}) reads the rows after GenomeSpy applies the display filter.

The HTML control changes shownLanes through the parameter API. GenomeSpy executes datum.lane < shownLanes in the browser. The application compares identifiers from the two returned tables; it does not reimplement the filter.

Scroll to zoom. Both tables inspect the whole loaded collection, so zooming alone does not filter their rows. “After the display filter” does not mean that every row currently produces visible pixels.

Source metadata describes readiness and coverage independently of retention. This complete eager fixture does not demonstrate lazy-source publication bounds.

<!-- category: feature -->

Publish reusable layouts, file inputs, dialogs, selection controls, data
previews, and form helpers in `@genome-spy/ui-components`. Applications can
import individual controls and theme them with scoped CSS custom properties.
GenomeSpy App and Playground use the shared components, and App's dialog exports
work alongside the new package.
